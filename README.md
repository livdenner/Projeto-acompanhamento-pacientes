# 🧩 Sistema de Avaliação de Pacientes e Terapias

Uma aplicação desktop desenvolvida em *Python* para auxiliar clínicas e profissionais no gerenciamento de pacientes (foco em Terapias) e na recomendação de atividades terapêuticas. O sistema utiliza uma interface gráfica moderna e armazenamento de dados local.

## 📋 Sobre o Projeto

Este software foi criado para facilitar o cadastro de fichas clínicas e oferecer suporte rápido com sugestões de jogos terapêuticos. Ele atende dois perfis de usuários:

1.  Profissionais: Podem cadastrar pacientes, buscar fichas e acessar dados clínicos detalhados.
2.  Pacientes/Responsáveis: Podem fazer login para visualizar suas informações.

### ✨ Funcionalidades Principais

* Autenticação Segura: Login diferenciado para profissionais e pacientes.
* Gestão de Pacientes:
* Módulo de Recomendações:
* Interface Gráfica: Design moderno (Dark Mode) utilizando a biblioteca CustomTkinter.

---

## 🛠️ Tecnologias Utilizadas

* Python: Linguagem principal.
* CustomTkinter: Para criação da interface gráfica.
* *JSON*: Para persistência local dos dados dos pacientes.

---

## 🚀 Como Executar o Projeto

### Pré-requisitos

Você precisará ter o Python instalado em sua máquina. Além disso, instale a biblioteca de interface gráfica:

```bash
pip install customtkinter
```
