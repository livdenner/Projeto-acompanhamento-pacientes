# 🧩 Sistema de Avaliação de Pacientes e Terapias

Uma aplicação desktop desenvolvida em Python para auxiliar clínicas e profissionais no gerenciamento de pacientes e na recomendação de atividades terapêuticas. O sistema utiliza uma interface gráfica moderna e armazenamento de dados local.

## 📋 Sobre o Projeto

Este software foi desenvolvido durante o primeiro semestre da graduação e foi criado para facilitar o cadastro de fichas clínicas e oferecer suporte rápido com sugestões de jogos terapêuticos.
<br>Ele possui as seguintes funcionalidades:
* Autenticação Segura: Login diferenciado para profissionais e pacientes.
* Gestão de Pacientes
* Módulo de Recomendações

## 🛠️ Tecnologias Utilizadas

* Python: Linguagem principal.

* *JSON*: Para persistência local dos dados dos pacientes.

## 🚀 Como Executar o Projeto

### Pré-requisitos

Você precisará ter o Python instalado em sua máquina. Além disso, instale a biblioteca de interface gráfica:

```bash
pip install customtkinter
```
